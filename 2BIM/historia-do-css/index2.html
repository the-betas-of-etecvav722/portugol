As caracteristicas do css: seletores, propriedades e valores

1. Seletores (Selectors) São usados para escolher quais elementos do HTML você quer estilizar. Exemplos: p { } Seleciona todos os

.botao { } Seleciona todos com class="botao" #menu { } Seleciona o elemento com id="menu"

2. Propriedades (Properties) São as características que você quer alterar. Exemplos comuns: color → cor do texto background → fundo font-size → tamanho da fonte margin → espaço externo padding → espaço interno

3. Valores (Values) São os valores que você dá para as propriedades. Exemplos: color: red; font-size: 20px; background: #000000; Tudo junto (estrutura completa) p { color: blue; font-size: 18px; } ✔ Aqui temos: p → seletor color e font-size → propriedades blue e 18px → valores Outro exemplo mais completo #botao { background-color: green; color: white; padding: 10px; }
