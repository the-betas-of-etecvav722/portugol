O que é CSS?

CSS, ou Cascading Style Sheets (Folhas de Estilo em Cascata), é uma linguagem de estilização usada para definir a aparência visual de páginas web, separando o conteúdo (HTML) do design. Ele controla cores, fontes, layouts, espaçamentos e responsividade. Não é uma linguagem de programação funcional, mas sim de estilo.

Principais Usos e Exemplos de CSS:Definir Layouts: Organizar elementos com Flexbox ou Grid.

Estilização de Texto: Alterar fontes, cores, tamanhos e alinhamentos.

Responsividade: Adaptar o site para celulares, tablets e desktop com @media queries.

Efeitos e Animações: Criar transições suaves, sombras e comportamentos interativos.

Estrutura de Cores: Aplicar estilos de fundo e bordas.


HTML é a estrutura base da web. Ele define todos os elementos que compõem uma interface digital.

No contexto cyberpunk, é o "corpo" do sistema.

Seletores

Selecionam quais elementos serão modificados pelo CSS.

  • h1 → títulos
  • .classe → grupos
  • #id → elemento único
h1 {
    color: cyan;
}

Propriedades

Definem o que será alterado.

  • color
  • font-size
  • background

Valores

Definem como a propriedade será aplicada.

p {
    color: #00ffe1;
    font-size: 18px;
}
